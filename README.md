# 将棋名人｜Shogi Master

**KASAI SOLUTIONS INC.** が提供する、PC・スマートフォン対応の将棋AI研究サイトです。盤面、両者の持ち駒、推奨手、読み筋、形勢、棋譜をまとめて確認できます。AIはブラウザ内で計算するため、APIキーや外部AIサービスへの登録は不要です。

公開先: https://uni-tadayasu.github.io/shogi-master/

## 対応機能

| 機能 | 内容 |
| --- | --- |
| 研究モード | 相手と自分の両方の駒を手動で動かし、その都度、手番側の候補手を解析 |
| AIと対局 | 相手側をAIが指す。自分が後手ならAIが初手を指す |
| 先手・後手 | 自分の手番を選択でき、盤面の向きも変更可能 |
| 候補手・読み筋 | 最大3候補、推奨矢印、探索深さ、評価値、読み筋 |
| 形勢判断 | 先手基準の評価値、優勢・劣勢の目安。棒グラフは実測勝率ではない |
| 戦法ガイド | おまかせを含む64の戦法・構想。分類別選択とカタログ検索 |
| 囲いガイド | 24の囲いの特徴・注意点を確認。具体的な手順はAI候補で検討 |
| 相手に合わせた自動調整 | 相手の飛車配置、攻めの進み方、王手などの局面特徴を用いてガイドを更新 |
| 持ち駒 | 両者の駒を図形と枚数で表示し、自分の手番で盤上に打てる |
| 棋譜 | 両者の指し手を記録し、任意の手を選んで局面を確認 |
| 巻き戻し・やり直し | 記録した最初の局面まで移動し、戻した手を進め直せる |
| 便利な機能 | 手数指定、30秒詳細解析、中断、矢印の表示切替、着手確認、SFEN・USIコピー |
| 保存・読込 | 端末内の自動保存、全手順と現在位置を保持するJSON v2、SFEN・USI position・JSONの読込 |

画面右上のスライダー形アイコンから「便利な機能・表示設定」を開けます。「戦法・構想カタログ」で名前・分類・特徴を検索し、同じ画面で目指す囲いも選べます。スマートフォンでは候補手と棋譜を横にスワイプして確認します。小さな画面や文字拡大時はスクロールが必要な場合があります。

## 指し方と戻し方

1. **研究・相手の手を入力**を選ぶと、両者の駒を操作できます。自分の手番を先手／後手で指定してください。
2. 駒をタップし、合法な移動先をタップします。持ち駒を打つ場合も同じです。選択可能な成りは確認画面が出ます。
3. AIの候補を選ぶと矢印と読み筋が切り替わります。「推奨手を指す」で盤面に反映できます。
4. 間違えた手は「一手戻す」で戻し、「やり直す」で進め直します。戻る操作では、まだ進めていない先の指し手を削除しません。最初へ戻るボタンや、便利な機能内の手数指定も利用できます。
5. 過去の局面から別の手を指すと、元の続きは保存した分岐として保持されます。分岐の保持は直近20件です。必要な棋譜はJSONでも保存してください。

最初へ戻れる範囲は、現在読み込んでいる棋譜に記録された範囲です。途中局面だけをSFENで読み込んだ場合、その局面より前の指し手は復元できません。インポートは20,000手までに制限しています。

JSON v2には、全手順と現在表示している位置（cursor）を保存します。途中まで戻してから書き出しても、先の手順を含めて保存・復元でき、読み込み後にやり直しできます。

AI対局モードで、相手側の手番の局面を読み込むと、AIが応手を指します。手動研究のまま保持したい場合は、読み込み前に研究モードへ切り替えてください。

## AIの能力と評価の意味

- エンジン: **YaneuraOu NNUE KP256 9.80git**（単一スレッドWebAssembly）
- 評価関数: **SuishoPetite 2021-11**
- 解析時間: 1秒・3秒・8秒・30秒

**必勝・世界最強・最新評価関数を保証する構成ではありません。** 将棋の強さはエンジン、評価関数、解析時間、端末の性能などで変わります。候補手や形勢は探索時点の推定であり、後から変わることがあります。候補ごとに探索深さが異なる場合もあります。

「相手に合わせて自動調整」は局面の特徴をもとにした方針ガイドです。定跡を完全に識別する機能や、常に最善の戦法を選ぶ保証ではありません。AIの候補手は、戦法ガイドとは独立に現在の局面から探索されます。選択した戦法や囲いでAIの探索候補を制限しません。すでに飛車を振った配置を無視して元へ戻すような、機械的な切り替えは行いません。

二歩、行き所のない駒打ち、自玉の王手放置、打ち歩詰め、成りの選択などを判定します。同一局面が4回出現すると千日手を、連続王手による繰り返しでは王手側の反則負けを判定します。

## GitHubへの公開

このサイトは静的ファイルだけで動作します。公開先リポジトリは `uni-tadayasu/shogi-master`、ブランチは `main` です。Pagesの公開元を **Deploy from a branch → main → /(root)** に設定します。以後、`main`の更新に応じて公開処理が実行されます。検証用のActionsは、ルールとAIエンジンの動作をチェックします。

ワークフローを使わず手動アップロードする場合は、ZIPを展開したフォルダーの**中身**をすべてアップロードしてください。リポジトリの最上位に `index.html`、`assets`、`engine-vendor` がある状態にします。ZIPをそのまま置くだけでは動きません。Pagesで **Deploy from a branch → main → /(root)** を選んでも静的ページを配信できます。

`index.html`をダブルクリックする`file://`起動では、ブラウザの制限でAIを読み込めません。GitHub PagesのHTTPS URL、または次のローカルサーバーを使用してください。

```sh
npm run dev
```

Node.jsが必要です。ブラウザで `http://127.0.0.1:4173/` を開きます。公開時にnpmの依存関係をインストールする必要はありません。

## 動作条件と保存データ

WebAssembly SIMD、ES Modules、Web Workers（Worker内からのWorker生成を含む）に対応したブラウザが必要です。データはこのブラウザのローカルストレージに保存され、別の端末へ自動同期されません。閲覧データの削除やプライベートブラウズにより記録が失われる場合があります。重要な棋譜はJSONでも書き出してください。
