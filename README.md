# 将棋名人｜Shogi Master

**KASAI SOLUTIONS INC.** が提供する、PC・スマートフォン対応の将棋AI研究サイトです。盤面、両者の持ち駒、推奨手、読み筋、形勢、棋譜をまとめて確認できます。AIはブラウザ内で計算するため、APIキーや外部AIサービスへの登録は不要です。

公開先: https://uni-tadayasu.github.io/shogi-master/

## 対応機能

| 機能 | 内容 |
| --- | --- |
| 研究モード | 相手と自分の両方の駒を手動で動かし、その都度、手番側の候補手を解析 |
| AIと対局 | 相手側をAIが指す。自分が後手ならAIが初手を指す |
| 先手・後手 | 自分の手番を選択でき、盤面の向きも変更可能 |
| 候補手・読み筋 | 初期設定は1秒・1候補の集中解析。比較用の3候補、推奨矢印、探索深さ、評価値、読み筋 |
| 形勢判断 | 先手基準の評価値、優勢・劣勢の目安。棒グラフは実測勝率ではない |
| 戦法ガイド | おまかせを含む64の戦法・構想。分類別選択とカタログ検索 |
| 囲いガイド | 24の囲いの特徴・注意点を確認。具体的な手順はAI候補で検討 |
| 相手に合わせた自動調整 | 相手の飛車配置、攻めの進み方、王手などの局面特徴を用いてガイドを更新 |
| 戦法変更の通知 | 「○○から△△に変わりました」と表示し、手数・理由を直近200件まで記録 |
| 独自戦法 | 戦法名・狙い・開始局面・手順を作成／編集し、実際の将棋AIで最終局面を解析 |
| ナレーション | 着手元・着手先、駒打ち・成り・駒取り、戦法変更、解析後の優勢／劣勢を日本語で読み上げ |
| 持ち駒 | 両者の駒を図形と枚数で表示し、自分の手番で盤上に打てる |
| 棋譜 | 両者の指し手を記録し、任意の手を選んで局面を確認 |
| 巻き戻し・やり直し | 記録した最初の局面まで移動し、戻した手を進め直せる |
| 便利な機能 | 手数指定、1秒集中解析、最大60秒の追加研究、解析メモリ設定、中断、矢印切替、着手確認、SFEN・USIコピー |
| 保存・読込 | 端末内の自動保存、全手順と現在位置を保持するJSON v2、SFEN・USI position・JSONの読込 |

「独自戦法」「音声 ON/OFF」「1秒集中解析」のショートカットから、よく使う研究機能へ移動できます。画面右上のスライダー形アイコンから「便利な機能・表示設定」を開けます。「戦法・構想カタログ」で名前・分類・特徴を検索し、同じ画面で目指す囲いも選べます。スマートフォンでは候補手と棋譜を横にスワイプして確認します。小さな画面や文字拡大時はスクロールが必要な場合があります。

## 指し方と戻し方

1. **研究・相手の手を入力**を選ぶと、両者の駒を操作できます。自分の手番を先手／後手で指定してください。
2. 駒をタップし、合法な移動先をタップします。持ち駒を打つ場合も同じです。選択可能な成りは確認画面が出ます。
3. AIの候補を選ぶと矢印と読み筋が切り替わります。「推奨手を指す」で盤面に反映できます。
4. 間違えた手は「一手戻す」で戻し、「やり直す」で進め直します。戻る操作では、まだ進めていない先の指し手を削除しません。最初へ戻るボタンや、便利な機能内の手数指定も利用できます。
5. 過去の局面から別の手を指すと、元の続きは保存した分岐として保持されます。分岐の保持は直近20件です。必要な棋譜はJSONでも保存してください。

最初へ戻れる範囲は、現在読み込んでいる棋譜に記録された範囲です。途中局面だけをSFENで読み込んだ場合、その局面より前の指し手は復元できません。インポートは20,000手までに制限しています。

JSON v2には、全手順と現在表示している位置（cursor）を保存します。途中まで戻してから書き出しても、先の手順を含めて保存・復元でき、読み込み後にやり直しできます。

AI対局モードで、相手側の手番の局面を読み込むと、AIが応手を指します。手動研究のまま保持したい場合は、読み込み前に研究モードへ切り替えてください。

## AIの能力と評価の意味

- エンジン: **YaneuraOu NNUE KP256 9.80git**（単一スレッドWebAssembly）
- 評価関数: **SuishoPetite 2021-11**
- 解析時間: **初期設定1秒**。1秒・3秒・8秒・15秒・30秒・60秒を選択可能
- 候補数: **初期設定1候補**に集中。比較時は3候補
- 探索キャッシュ: 32 / 64 / 128MB。スマートフォン・低メモリ端末は32MB、PCは64MBを基本とする

1秒はエンジンの探索時間です。初回のファイル読込・WASM起動・メモリ確保・画面更新は別に時間がかかります。完了済みのエンジンは再利用し、設定が変わらなければ探索キャッシュも維持します。探索中の局面変更や中断では古い結果を混ぜないよう内部Workerを再起動します。

**1秒で常に最善手、必勝、世界最強、最新評価関数を保証する構成ではありません。** 将棋の強さはエンジン、評価関数、解析時間、端末の性能などで変わります。候補手や形勢は探索時点の推定であり、後から変わることがあります。候補ごとに探索深さが異なる場合もあります。

「相手に合わせて自動調整」は局面の特徴をもとにした方針ガイドです。定跡を完全に識別する機能や、常に最善の戦法を選ぶ保証ではありません。AIの候補手は、戦法ガイドとは独立に現在の局面から探索されます。選択した戦法や囲いでAIの探索候補を制限しません。すでに飛車を振った配置を無視して元へ戻すような、機械的な切り替えは行いません。

二歩、行き所のない駒打ち、自玉の王手放置、打ち歩詰め、成りの選択などを判定します。同一局面が4回出現すると千日手を、連続王手による繰り返しでは王手側の反則負けを判定します。

## 独自戦法をAIと研究する

1. 盤上で研究したい手順を指し、「独自戦法」→「盤面から取り込む」で現在の表示位置まで取り込みます。
2. 名前、研究する側、参考にする基本戦法、狙い・研究メモを編集します。開始局面のSFENやUSI手順を直接編集することもできます。
3. 「手順を確認」で全手が合法か検証し、「この手順をAI解析」で**最後の局面**をやねうら王に渡します。
4. 候補手・読み筋・研究する側から見た評価値を確認し、「この候補を手順に追加」で続きを組み立てられます。相手番なら相手の候補が追加されます。
5. 「保存する」、または「保存して盤面に適用」で研究を続けます。保存した独自戦法は戦法選択欄からも選べます。

独自戦法は最大50件、1件につき512手までです。元の開始局面と両者の手順を保持し、完全に一致する局面でのみ保存した次の手を参考手として表示します。自動調整を有効にした場合、相手の配置などによって基本戦法から方針が変わる場合があります。

この機能は、実際の将棋エンジンによる局面解析と手順編集を組み合わせた研究室です。文章生成AI（LLM）や、研究メモの文章を読んで意図を理解する機能ではありません。登録した手順でエンジン自体を再学習させるものでもありません。

保存場所はこのブラウザ内です。「全戦法を書き出す」でJSONを保管でき、別の端末では「JSONを読み込む」で取り込めます。未保存の編集は書き出しに含まれません。自動クラウド同期はありません。読み込みファイルは1MBまでで、同じIDを持つ戦法は既存データを上書きせず別名で追加します。

## 戦法変更の通知とナレーション

最初に選んだ戦法を画面に表示し、自動調整・手動選択などで方針が変わると「○○から△△に変わりました」と通知します。「便利な機能」内の「戦法の変化」には、手数と変更理由を直近200件まで残します。過去の棋譜を表示し直した操作は、新たな戦法変更として重複記録しません。新しい対局を開始すると、その対局の戦法変更履歴はリセットします。

ナレーションは**ページを開くたびにOFF**で始まります。「音声 OFF」を押すとONになり、現在の局面を読み上げます。着手元と着手先、持ち駒を打った場所、駒取り・成り、戦法変更、AI解析後の形勢を読み上げます。手数と文章も画面で確認できます。

「便利な機能」で日本語音声と速度（0.7〜1.5倍）を選び、現在の局面の読み直しや停止ができます。日本語音声を備えたOSと、ブラウザの音声合成機能が必要です。対応音声がない場合は状態メッセージを表示し、英語音声へ勝手に切り替えません。画面を離れたときや棋譜を巻き戻したときは、古い局面の読み上げを停止します。マイクによる録音は行いません。

## GitHubへの公開

このサイトは静的ファイルだけで動作します。公開先リポジトリは `uni-tadayasu/shogi-master`、ブランチは `main` です。Pagesの公開元を **Deploy from a branch → main → /(root)** に設定します。以後、`main`の更新に応じて公開処理が実行されます。検証用のActionsは、ルールとAIエンジンの動作をチェックします。

ワークフローを使わず手動アップロードする場合は、ZIPを展開したフォルダーの**中身**をすべてアップロードしてください。リポジトリの最上位に `index.html`、`assets`、`engine-vendor` がある状態にします。ZIPをそのまま置くだけでは動きません。Pagesで **Deploy from a branch → main → /(root)** を選んでも静的ページを配信できます。

`index.html`をダブルクリックする`file://`起動では、ブラウザの制限でAIを読み込めません。GitHub PagesのHTTPS URL、または次のローカルサーバーを使用してください。

```sh
npm run dev
```

Node.jsが必要です。ブラウザで `http://127.0.0.1:4173/` を開きます。公開時にnpmの依存関係をインストールする必要はありません。

### 独自戦法の参考勝率

独自戦法のAI候補には、研究する側の評価値を `1 / (1 + exp(-評価値 / 600))` で換算した「参考勝率」を表示します。本アプリで選んだ未校正の換算式であり、SuishoPetiteの実戦データで検証された勝率・勝利予測ではありません。表示は1〜99%に制限します。評価が範囲（bound）・未取得の場合は割合を出さず、詰み評価は「詰み筋」と表示します。相手の棋力や持ち時間に基づく実測勝率は算出しません。

保存済み戦法と先後・開始局面・全手順が一致する場合に限り、最新の解析結果を端末に最大50件保持します。保存結果には日時・解析時間設定・探索深さを表示し、新規解析とは区別します。手順や先後を変更すると以前の割合は非表示になります。JSON書き出しには戦法の手順・メモを含み、解析履歴は含めません。
